# بوت توليد ومراجعة المنشورات اليومية (مجاني 100%)

نظام بسيط: يولّد منشور يومي (LinkedIn / TikTok-Snapchat / Instagram-Facebook) عبر Gemini،
يرسله لك على تليجرام بأزرار **موافقة / تعديل / رفض**، ويحفظ المعتمد في شات أرشفة دائم.
شغّال 24 ساعة مجانًا على Render بدون ما تفتح جهازك.

---

## الخطوة 1: اعمل بوت تليجرام

1. افتح تليجرام وابحث عن `@BotFather`.
2. ابعت `/newbot` واتبع الخطوات (اسم + username ينتهي بـ bot).
3. هيديك **Token** شكله `123456789:ABC-XYZ...` — احفظه.
4. ابعت أي رسالة لبوتك الجديد (عشان يكون فيه محادثة تقدر تاخد الـ chat_id منها).
5. افتح في المتصفح:
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
   وهتلاقي `"chat":{"id": 123456789, ...}` — الرقم ده هو `TELEGRAM_CHAT_ID`.

(اختياري) لو عايز أرشيف منفصل للمعتمد: اعمل قناة تليجرام خاصة، ضيف بوتك فيها كـ Admin،
وابعت رسالة، وهات الـ chat id بتاعها بنفس الطريقة (هيبدأ بـ `-100...`) — ده `TELEGRAM_LOG_CHAT_ID`.

---

## الخطوة 2: مفتاح Gemini API (مجاني)

1. ادخل `aistudio.google.com`.
2. سجل دخول بحساب جوجل، واعمل **Create API key**.
3. احفظ المفتاح — ده `GEMINI_API_KEY`.

---

## الخطوة 3: ارفع المشروع على GitHub

1. اعمل حساب مجاني على github.com لو مالكش.
2. اعمل Repository جديد (خاص أو عام، مش فارق).
3. ارفع كل ملفات المشروع ده (main.py, requirements.txt, Procfile, README.md).
   (أسهل طريقة: من الموقع نفسه، زرار "Add file" → "Upload files" واسحب الملفات).

---

## الخطوة 4: النشر على Render (مجاني 24 ساعة)

1. سجل دخول على `render.com` بحساب GitHub.
2. **New +** → **Web Service** → اختار الـ Repository اللي رفعته.
3. الإعدادات:
   - **Runtime:** Python 3
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn main:app`
   - **Plan:** Free
4. في تبويب **Environment**، ضيف المتغيرات دي (من ملف `.env.example`):
   `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `TELEGRAM_LOG_CHAT_ID`,
   `GEMINI_API_KEY`, `GEMINI_MODEL`, `GENERATE_SECRET`, `WEBHOOK_SECRET_PATH`, `CONTENT_NICHE`
   (اختار قيم عشوائية طويلة لـ `GENERATE_SECRET` و `WEBHOOK_SECRET_PATH`، أي حاجة يصعب حد يخمنها).
5. اضغط **Create Web Service** وانتظر لحد ما يخلص Deploy.
6. هتاخد رابط شكله: `https://your-app-name.onrender.com`

> ملحوظة: الخطة المجانية في Render "بتنام" بعد ٱ١٥ دقيقة من غير طلبات، وبتصحى تاني تلقائي
> لما توصلها طلب (بتاخد ٣٠-٥٠ ثانية أول مرة). ده مش مشكلة لأننا هنستخدم Cron خارجي (الخطوة 6) بيصحيها.

---

## الخطوة 5: اربط الويبهوك (عشان الأزرار تشتغل)

بعد ما يخلص الـ Deploy، افتح في المتصفح (غيّر TOKEN والرابط والـ SECRET بتاعتك):

```
https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://your-app-name.onrender.com/telegram-webhook/<WEBHOOK_SECRET_PATH>
```

لو ظهرت `"ok":true` يبقى الويبهوك اتظبط. من دلوقتي أي ضغطة زرار أو رسالة هتوصل لتطبيقك.

---

## الخطوة 6: جدولة التوليد اليومي (مجاني)

استخدم موقع **cron-job.org** (مجاني بالكامل):

1. سجل حساب مجاني.
2. اعمل **Create cronjob**.
3. الرابط (URL):
   `https://your-app-name.onrender.com/generate?key=<GENERATE_SECRET>`
4. حدد التوقيت (مثلاً كل يوم الساعة 9 صباحًا بتوقيتك).
5. احفظ.

من دلوقتي، كل يوم في الميعاد ده هيوصلك على تليجرام مسودة المنشور بأزرار موافقة/تعديل/رفض.

---

## اختبار سريع فورًا (من غير ما تستنى الميعاد)

- ابعت للبوت بتاعك في تليجرام الأمر `/generate` وهيولّدلك مسودة على طول.
- أو افتح في المتصفح: `https://your-app-name.onrender.com/generate?key=<GENERATE_SECRET>`

---

## إزاي تستخدم الأزرار

- **🟢 موافقة:** يتحفظ المنشور في شات/قناة الأرشفة (`TELEGRAM_LOG_CHAT_ID`) — تنسخه من هناك وتنشره
  يدويًا، أو تطوّر الكود بعدين يبعته أوتوماتيك لأداة زي Buffer/Metricool.
- **✏️ تعديل:** يطلب منك ملاحظاتك كرسالة نصية، وبمجرد ما تبعتها هيعيد الصياغة ويبعتلك نسخة جديدة
  بنفس الأزرار.
- **🔴 رفض:** يلغي المسودة، وهتستنى الميعاد الجاي (أو تبعت `/generate` يدوي لمسودة جديدة فورًا).

---

## تخصيص أسلوب المحتوى

غيّر قيمة `CONTENT_NICHE` في Environment Variables على Render لوصف مجالك بدقة أكتر
(مثلاً: "لايف ستايل ورياضة"، "أكل ووصفات منزلية"، "تطوير ذاتي وريادة أعمال")، وممكن كمان
تعدّل نص `BASE_PROMPT` جوه `main.py` لو عايز تغيّر شكل الأقسام نفسها.

---

## حدود ومعرفة مهمة

- التخزين بسيط (ملف JSON على السيرفر) — يكفي تمامًا للاستخدام الشخصي، لكن لو السيرفر
  اتعمله Redeploy وفي مسودة لسه مش متردود عليها، ممكن تضيع (المعتمد المُرسل لقناة الأرشفة
  آمن دايمًا لأنه بيتبعت كرسالة تليجرام عادية).
- النشر الفعلي على المنصات (فيسبوك/انستجرام/تيك توك...) مش أوتوماتيك في النسخة دي —
  البوت بيجهزلك المحتوى ويحفظه بعد موافقتك، وتنشره يدويًا أو تربطه بأداة زي Buffer/Metricool
  لاحقًا لو حبيت (نقدر نضيف الخطوة دي كمان لو عايز).
